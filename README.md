## 🚀 About the Project

Neon Hacker Terminal is an interactive, cyberpunk-style web application created using HTML, CSS, and JavaScript. It features a neon-green interface, a simulated hacking console, a progress bar, and an exciting secret cipher mini-game.

This project was developed as part of the AI Coding Lab assignment to explore AI-assisted coding, debugging, and software testing.

## 🎮 How to Use

1. Open the live demo link.
2. Use the mission console to run the simulated hacking commands.
3. Try the network scan and watch the progress bar.
4. Solve the secret cipher by shifting each letter three positions backward.
5. Open the browser Developer Console to check the JavaScript tests.

## 🔐 Secret Features

- Cyberpunk-inspired neon interface.
- Interactive simulated hacking commands.
- Animated mission progress bar.
- Secret cipher puzzle.
- JavaScript edge-case tests using `console.assert()`.
- Debugging practice and code explanation comments.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🧪 Testing

The application includes automated `console.assert()` tests to check normal, zero, negative, and oversized progress values.

This application is an educational simulation only. It does not hack real systems or access real networks.
